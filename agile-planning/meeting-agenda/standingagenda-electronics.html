Epic Evaluation Loop (~4 min/epic)
1. System requirement clear after reading the epic? If not, mark needs-info and move on.
2. Required for 2TS? If yes, set priority rank.
3. How many stories to deliver this epic? Capture count + story titles.
4. Estimate time per story in days.
5. Roll-up (auto = story count × days/story).
6. Blocking epics by ID — hard (can't start) vs soft (can start, can't finish). Blocking Epics resolves within THIS sheet only; a dependency on an Embedded-Core epic is recorded at the capability level, not here.
